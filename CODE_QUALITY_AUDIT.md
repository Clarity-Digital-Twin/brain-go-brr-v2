**Code Sample Analysis:**

**GOOD (from `detector.py`):**
```python
def _run_node_stream(self, features: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
    """Process node-level features through temporal stream.

    Args:
        features: Electrode features (B, C, T)

    Returns:
        (node_features, electrode_features): Processed tensors
    """
    temporal = self.node_mamba(features) if self.node_mamba else features
    temporal = assert_finite(temporal, "node_stream_output")
    elec_feats = temporal.mean(dim=-1)  # (B, C, T) -> (B, C)
    return temporal, elec_feats
```

**Analysis:**
- ✅ **Descriptive function name:** `_run_node_stream` (not `process_data`)
- ✅ **Type hints:** Clear input/output types
- ✅ **Domain variables:** `elec_feats`, `temporal` (not `x`, `y`)
- ✅ **Proper docstring:** Args + Returns (not excessive)
- ✅ **Finite assertion:** Safety checks for NaN/Inf
