## Component Details

### 1. NPZ Cache Files

**Purpose**: Store pre-processed EEG windows and labels for fast loading

**Creation**: Generated by `EEGWindowDataset.__init__()` or `build-cache` CLI command

**Format**:
```python
{
    "windows": np.ndarray,  # Shape: (n_windows, 19, 15360) - float32
    "labels": np.ndarray,   # Shape: (n_windows, 15360) - float32
}
```

**CRITICAL**: Some NPZ files contain ZERO windows because:
- Recording duration < 60s (minimum window size)
- Recording entirely artifacts (removed during preprocessing)
- Recording gap between seizure annotations (no valid data)

**Statistics**:
- Train: 4667 NPZ files total, 229 with zero windows (4.9%)
- Dev: 1832 NPZ files total, 224 with zero windows (12.2%)

**Verified**: All zero-window files load successfully without errors ✅

### 2. Manifests (manifest.json)

**Purpose**: Categorize windows by seizure content for balanced sampling

**Created by**: `scan_existing_cache()` in `src/brain_brr/data/cache_utils.py:67-145`

**Used by**: `BalancedSeizureDataset` (training only)

**Format**:
```json
{
  "partial_seizure": [
    {"cache_file": "file1_windows.npz", "window_idx": 0},
    {"cache_file": "file1_windows.npz", "window_idx": 1}
  ],
  "full_seizure": [
    {"cache_file": "file2_windows.npz", "window_idx": 5}
  ],
  "no_seizure": [
    {"cache_file": "file3_windows.npz", "window_idx": 0}
  ]
}
```

**Categorization Logic** (cache_utils.py:116-127):
```python
for w_idx in range(n_windows):
    lbl = labels[w_idx]
    ratio = (lbl > 0).mean()

    if ratio == 0.0:
        category = "no_seizure"
    elif ratio >= 0.99:
        category = "full_seizure"
    else:
        category = "partial_seizure"
```

**Coverage**:
- Train: 4438/4667 files (95.1%) - excludes 229 zero-window files ✅
- Dev: 1608/1832 files (87.8%) - excludes 224 zero-window files ✅

**Rebuild Triggers**:
- Manual: `python -m src scan-cache --cache-dir cache/tusz/train`
- Auto: `scan_existing_cache(cache_dir)` called during training setup
- Environment: `BGB_FORCE_MANIFEST_REBUILD=1`

**Design Decision**: Manifests **intentionally exclude** zero-window files to:
- Prevent divide-by-zero when calculating ratios
- Avoid empty file references in dataset
- Maintain clean categorization (no "unknown" category needed)

### 3. Dataset Index (_dataset_index.json)

**Purpose**: Cache window counts per file for fast dataset initialization

**Created by**: `EEGWindowDataset.__init__()` in `src/brain_brr/data/datasets.py:54-77`

**Used by**: `EEGWindowDataset` (validation only)

**Format**:
```json
{
  "files": [
    "data_ext4/tusz/edf/dev/aaaaaajy/s001_2003/02_tcp_le/aaaaaajy_s001_t000.edf",
    "data_ext4/tusz/edf/dev/aaaaaajy/s002_2003/01_tcp_ar/aaaaaajy_s002_t000.edf"
  ],
  "window_counts": [42, 0]
}
```

**Validation Logic** (datasets.py:65-77):
```python
# Load cached index
cached_files = [Path(p).name for p in cached_index["files"]]
current_files = [p.name for p in self.edf_files]

if cached_files == current_files:
    # Use cached counts (INSTANT)
    self._file_window_counts = cached_index["window_counts"]
else:
    # File list changed - rebuild (5-10 MINUTES)
    # This happens when switching smoke ↔ full mode
```

**Coverage**: Includes ALL files (even zero-window files) because:
- EEGWindowDataset needs to know total window count = 0 for indexing
- Dataset can return empty list of windows for zero-window files
- No categorization needed (just sequential access)

**Invalidation**: Index is rebuilt when:
- File list changes (smoke ↔ full mode switch)
- Any EDF file in list is modified
- Index file is deleted

**Performance**:
- With valid index: <1 second load time ✅
- Without index: 5-10 minutes scanning 1832 files ⚠️

### 4. BalancedSeizureDataset (Training)

**Purpose**: Implement SeizureTransformer-style class balancing for training

**Location**: `src/brain_brr/data/datasets.py:252-399`

**Used by**: Training dataset ONLY

**Sampling Strategy**:
```python
# All partial seizure windows (most informative)
ALL partial_seizure windows  # 100%

# Subsample other categories
+ 0.3x partial count of full_seizure windows
+ 2.5x partial count of no_seizure windows
```

**Why Balanced Sampling**:
- Raw TUSZ has ~8% seizure windows (severe imbalance)
- Model needs ~30% seizure exposure to learn patterns
- Standard practice: Train on balanced data, validate on real distribution

**Load Time**: <1 second (reads manifest directly) ✅

**Dependencies**: Requires `manifest.json` to exist

**Fallback**: If manifest missing or invalid, falls back to `EEGWindowDataset`

### 5. EEGWindowDataset (Validation)

**Purpose**: Sequential window access with natural class distribution

**Location**: `src/brain_brr/data/datasets.py:26-250`

**Used by**:
- Validation dataset (intentional - measures real-world performance)
- Training dataset (fallback if manifest unavailable)

**Load Strategy**:
```python
# Try to load cached index
if _dataset_index.json exists AND file_list matches:
    Load counts from index  # <1 second ✅
else:
    Scan all NPZ files to build index  # 5-10 minutes ⚠️
    Save new index for next run
```

**Why NOT Use Manifest for Validation**:
1. **Natural distribution** - validation must measure real-world performance (8% seizures)
2. **No sampling** - validation uses ALL windows sequentially
3. **Reproducibility** - same validation set every run (no random sampling)

**Design**: This is CORRECT behavior, not a bug!

## Validation Startup Delay - Root Cause Analysis

### Observed Behavior

```bash
[13:21:48] INFO [BalancedSeizureDataset] Created with 61616 windows
                                          ↑ INSTANT (reads manifest)

[13:21:48] INFO [DATA] Building dataset index for 1832 files...
[13:21:51] INFO [DATA] Processing file 11/1832: aaaaaajy_s004_t000.edf
[13:24:55] INFO [DATA] Processing file 351/1832: aaaaahie_s023_t002.edf
                                          ↑ 5-10 MINUTES (scanning NPZ)
```

### Root Cause

The index is being **invalidated and rebuilt** because:

**Hypothesis 1: File Path Mismatch** (MOST LIKELY)
```python
# Index stores FULL paths
cached_files = ["data_ext4/tusz/edf/dev/aaaaaajy/s001_2003/02_tcp_le/aaaaaajy_s001_t000.edf"]

# Current files might use DIFFERENT path format
current_files = ["data/tusz/edf/dev/aaaaaajy/s001_2003/02_tcp_le/aaaaaajy_s001_t000.edf"]

# Comparison fails even though it's the same files!
if cached_files == current_files:  # FALSE due to "data_ext4" vs "data"
    # Never executed - index is rebuilt
```

**Hypothesis 2: Smoke/Full Mode Switching**
- Smoke mode: Uses 3-50 files
- Full mode: Uses 1832 files
- Index is rebuilt when switching between modes

**Hypothesis 3: Index Corruption**
- Index might be getting corrupted or truncated
- JSON parsing fails, triggering rebuild

## Zero-Window Files - Deep Dive

### Why Do Zero-Window Files Exist?

**Windowing Parameters** (from constants.py):
```python
WINDOW_SIZE_SEC = 60    # 60-second windows
STRIDE_SIZE_SEC = 10    # 10-second stride
WINDOW_SAMPLES = 15360  # 60s × 256 Hz
STRIDE_SAMPLES = 2560   # 10s × 256 Hz
```

**Windowing Logic** (from windows.py):
```python
n_windows = max(0, (n_samples - window_size) // stride + 1)

# Examples:
# Recording 45s (11,520 samples) → 0 windows (< 60s minimum)
# Recording 65s (16,640 samples) → 1 window
# Recording 120s (30,720 samples) → 7 windows
```

**Common Causes**:
1. **Short recordings**: Many TUSZ recordings are <60s (single seizure event)
2. **Preprocessing artifacts**: Entire recording flagged as artifact and zeroed out
3. **Edge cases**: Recordings with large gaps or missing channels

### Are Zero-Window Files Corrupted?

**NO!** Verified with test:
```python
# ALL 453 zero-window files load successfully
# ALL have valid "windows" and "labels" keys
# ALL have shape: (0, 19, 15360) and (0, 15360)
# This is VALID numpy - empty array with correct dimensions
```

### Should Manifests Include Zero-Window Files?

**NO!** Current behavior is correct:
- Manifest categorizes WINDOWS, not files
- Zero-window files have no windows to categorize
- Including them would require special "empty" category (unnecessary complexity)
- BalancedSeizureDataset can't sample from empty files anyway

### Should Dataset Index Include Zero-Window Files?

**YES!** Current behavior is correct:
- EEGWindowDataset needs to know window_count = 0 for proper indexing
- Dataset can return empty result for index ranges that hit zero-window files
- Index stores counts, not categories, so count=0 is valid

## Current Issues and Recommendations

### Issue 1: Validation Startup Delay ⚠️

**Symptom**: Validation takes 5-10 minutes to initialize on every training run

**Root Cause**: Dataset index invalidation due to:
1. Path format changes (data_ext4 vs data)
2. Smoke ↔ Full mode switching
3. Index corruption

**Impact**:
- Development velocity: ~30 min wasted per 3-run cycle
- Modal GPU costs: ~$1-2 wasted per training run
- User frustration

**Recommendations** (in priority order):

#### Option A: Use Manifest for Validation (RECOMMENDED)

Create `BalancedSeizureDataset` variant for validation:

```python
# In datasets.py
class ValidationDataset(BalancedSeizureDataset):
    """Validation dataset using manifest WITHOUT balanced sampling."""

    def __init__(self, cache_dir: Path, seed: int | None = 42):
        # Call parent with ratios that use ALL windows
        super().__init__(
            cache_dir,
            full_ratio=1000.0,      # Use ALL full seizure windows
            background_ratio=1000.0, # Use ALL background windows
            seed=seed
        )
        # Result: ALL windows from manifest, natural distribution
```

**Pros**:
- Instant load (<1 second)
- No index invalidation issues
- Consistent with training dataset (both use manifests)
- Natural distribution maintained (no balancing)

**Cons**:
- Excludes zero-window files (but they contribute zero windows anyway)

**Implementation**:

## Testing Recommendations

### Test 1: Manifest Coverage

```python
def test_manifest_excludes_zero_window_files():
    """Verify manifests correctly exclude zero-window files."""
    cache_dir = Path("cache/tusz/dev")

    # Get all NPZ files
    all_npz = list(cache_dir.glob("*.npz"))

    # Find zero-window files
    zero_window_files = set()
    for npz_path in all_npz:
        with np.load(npz_path) as data:
            if data["windows"].shape[0] == 0:
                zero_window_files.add(npz_path.name)

    # Load manifest
    with open(cache_dir / "manifest.json") as f:
        manifest = json.load(f)

    # Get files in manifest
    manifest_files = set()
    for category in ["partial_seizure", "full_seizure", "no_seizure"]:
        for item in manifest[category]:
            manifest_files.add(item["cache_file"])

    # Verify no overlap
    assert not (zero_window_files & manifest_files), \
        "Manifest should not include zero-window files"

    # Verify all non-zero files are included
    non_zero_files = {p.name for p in all_npz} - zero_window_files
    assert non_zero_files == manifest_files, \
        "Manifest should include all non-zero-window files"
```
